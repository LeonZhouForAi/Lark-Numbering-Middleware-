# 隐藏员工可见来源信息设计

## 目标

机器人回答不再向员工展示“来源”区块或 `[1]`、`[2]` 等引用编号，同时保留后台引用对象，供故障排查和后续审计使用。

## 当前行为

RAG 服务在本地完成文档解析、OCR、切片和检索。DeepSeek 只接收检索命中的片段并生成回答。当前生成结果会附加“来源”列表，提示词也允许模型输出资料编号。

## 设计

1. 保留 `RagAnswer.citations`，不改变内部检索结果和来源追踪。
2. 员工可见的 `RagAnswer.text` 只返回 DeepSeek 生成的正文，不再拼接“来源”列表。
3. 修改系统提示词，明确要求不输出资料编号、引用编号或来源列表。
4. 无命中时的固定提示保持不变。
5. 飞书消息处理、消息去重、自动同步、OCR 和 DeepSeek 配置保持不变。

## 数据流

文档在服务器本地解析与切片，SQLite 检索命中片段，DeepSeek 根据命中片段生成无引用编号的正文。引用元数据仍随 `RagAnswer` 保留，但不会发送给飞书用户。

## 错误处理

模型调用失败时沿用现有异常处理。隐藏来源不会改变重试和消息去重行为。

## 测试

1. 有命中时，回答文本不包含“来源：”。
2. 系统提示词明确禁止输出 `[1]` 等引用编号。
3. 内部 `citations` 仍包含命中文档信息。
4. 全部现有测试继续通过。

## 非目标

- 不使用 DeepSeek 进行文档切片。
- 不改变本地关键词检索算法。
- 不删除后台来源数据。
- 不修改知识库同步频率或权限。
