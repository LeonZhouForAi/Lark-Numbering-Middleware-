# v0.4.0 检索质量与费用治理实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务执行。步骤使用复选框跟踪。

**目标：** 在不增加外部基础设施的前提下，完成 FTS5/BM25 混排、相关度门槛、结构化安全回答、API 重试与用量统计、员工限流和 ACL 检索边界。

**架构：** SQLite 继续承担索引与治理状态；FTS 只生成候选，confidence 决定证据是否足够。消息链路在去重后执行哈希限流，RAG 只接收匿名原文上下文，外部 API 重试严格区分幂等写入。

**技术栈：** Python 3.14、SQLite FTS5、FastAPI、Lark SDK、DeepSeek Chat Completions、pytest。
