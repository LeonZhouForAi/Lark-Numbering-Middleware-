# v0.9.0 IE 结构化精确查询实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 从 IE XLSX 原值构建结构化事实，并在员工询问 UPPH、系列工时或料号工时时优先精确查询，避免模型计算或编造数字。

**架构：** `structured_facts.py` 从工作簿识别三种受控表型并输出不可变事实；`store.py` 在文档快照更新后事务性替换来源事实；`exact_query.py` 只解析三类明确意图并查询 SQLite。`RagService` 在普通 FAQ/RAG 前尝试精确查询，条件缺失时只追问一个字段，无精确结果时回退现有 RAG。

**技术栈：** Python 3.14、openpyxl、SQLite、现有 RAG/FAQ、pytest。
