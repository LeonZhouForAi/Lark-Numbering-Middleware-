# v0.3.0 索引生命周期与质量门禁实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法跟踪。

**目标：** 让飞书索引能安全清理失效制度，完整提取父页面、DOCX 表格和混合 PDF，并用不含制度正文的金标集自动衡量检索与回答质量。

**架构：** 每个飞书空间只有“完整成功快照”才有删除权；存储层提供受前缀约束的清理 API。解析层按文档顺序提取 DOCX 可见内容并按页 OCR；评估层独立于生产 RAG，读取 JSON 金标并只输出指标。

**技术栈：** Python 3.14、SQLite、python-docx 1.2、pypdf、pdf2image、Tesseract、pytest。
