# v0.5.0 高频问答索引实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在不引入向量数据库的前提下，为飞书 RAG 增加最近 15 天累计 3 次自动启用、随资料版本自动失效和刷新的高频问答缓存。

**架构：** `IndexStore` 新增知识库版本、FAQ、别名、观察桶和指标表，并只在完整成功的索引同步后递增版本。`FaqService` 基于问题归一化、同义词和本地检索的文档特征匹配有效缓存；`RagService` 在调用 DeepSeek 前查询 FAQ，在普通 RAG 回答安全通过后记录观察并自动晋级。缓存命中仍保留现有限流、消息去重和输出安全检查。

**技术栈：** Python 3.14、SQLite WAL/FTS5、FastAPI、飞书长连接、DeepSeek OpenAI 兼容 API、pytest。

```python
def knowledge_revision(self) -> int:
    row = self.connection.execute(
        "SELECT revision FROM knowledge_state WHERE singleton_id = 1"
    ).fetchone()
    return int(row[0])


def bump_knowledge_revision(self, *, now: float | None = None) -> int:
    changed_at = time.time() if now is None else now
    with self.connection:
        self.connection.execute(
            "UPDATE knowledge_state SET revision = revision + 1, updated_at = ? "
            "WHERE singleton_id = 1",
            (changed_at,),
        )
    return self.knowledge_revision()
```

`bump_knowledge_revision()` 使用单条更新语句递增 `revision` 并返回更新后的值；不在 `upsert_document()` 中自动调用。

- `cleanup_faq(*, cutoff_day: str, stale_cutoff: float) -> dict[str, int]`：删除过期观察桶和超过保留期的失效条目。
