# v0.7.0 回答质量控制实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将问答结果明确分为可回答、问题有歧义、证据不足和完全无资料，并用固定题库与发布阈值阻止低质量版本进入生产。

**架构：** 不增加第二次模型调用。无检索结果由本地判定为 `missing`；有检索结果时，DeepSeek 在现有回答 JSON 中返回 `answerable`、`ambiguous` 或 `insufficient`。中间件严格验证状态：歧义问题只输出一个澄清问题，证据不足输出固定提示，可回答内容经过现有来源与敏感信息清洗。评测层只保存状态和聚合指标，不保存回答正文。

**技术栈：** Python 3.14、SQLite/FTS5、DeepSeek JSON、pytest。
